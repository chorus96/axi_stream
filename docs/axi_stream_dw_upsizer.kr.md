# AXI Stream 데이터 폭 업사이저

이 모듈은 좁은 AXI-Stream을 임의 크기의 더 넓은 AXI-Stream으로 변환한다. 출력 스트림의 데이터 폭은 입력 스트림 데이터 폭의 정수배여야 하며, 출력 데이터 폭은 입력 데이터 폭보다 엄격히 커야 한다. 데이터는 데이터 폭 변환에 따른 고유 지연에 더하여 1 클록 사이클 추가 지연 후 출력된다 (패스스루 없음).


## 신호 전달 특성

- **TVALID** → 상태 다이어그램 참조
- **TREADY** → 상태 다이어그램 참조
- **TSTRB** → 바이트 단위로 보존
- **TKEEP** → 바이트 단위로 보존 (주의: TKEEP가 디어서트된 전송은 데이터 스트림에서 제거되지 않음)
- **TLAST** → 사양에 따라 마지막 (출력) 트랜스퍼에서 어서트됨
- **TID** → 출력 트랜스퍼를 구성하는 마지막 서브 트랜스퍼의 데이터만 전달됨
- **TDEST** → 출력 트랜스퍼를 구성하는 마지막 서브 트랜스퍼의 데이터만 전달됨
- **TUSER** → 출력 트랜스퍼를 구성하는 마지막 서브 트랜스퍼의 데이터만 전달됨
