# AXI Stream 데이터 폭 다운사이저

이 모듈은 임의 크기의 AXI-Stream을 더 좁은 AXI-Stream으로 변환한다. 입력 스트림의 데이터 폭은 출력 스트림 데이터 폭의 정수배여야 하며, 입력 데이터 폭은 출력 데이터 폭보다 엄격히 커야 한다. 입력 포트에서 수신된 데이터는 1 클록 사이클 후에 출력 포트에 나타난다 (패스스루 없음).


## 신호 전달 특성

- **TVALID** → 상태 다이어그램 참조
- **TREADY** → 상태 다이어그램 참조
- **TSTRB** → 바이트 단위로 보존
- **TKEEP** → 바이트 단위로 보존 (주의: TKEEP가 디어서트된 전송은 데이터 스트림에서 제거되지 않음)
- **TLAST** → 사양에 따라 마지막 서브 트랜스퍼에서 어서트됨
- **TID** → 모든 서브 트랜스퍼에서 완전히 전달됨
- **TDEST** → 모든 서브 트랜스퍼에서 완전히 전달됨
- **TUSER** → 모든 서브 트랜스퍼에서 완전히 전달됨
